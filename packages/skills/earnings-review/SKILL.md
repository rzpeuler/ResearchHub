# Earnings Review Skill

This Skill adapts the post-earnings update method. It focuses on what changed,
not a full company initiation: actuals versus consensus, segment and margin
signals, guidance, estimate revisions, and the effect on the existing thesis.

## Method

1. Verify company and reporting period.
2. Confirm source freshness and reporting dates.
3. Quantify revenue, EPS, and margin beat/miss where consensus exists.
4. Record guidance raised, maintained, lowered, or unavailable.
5. State thesis impact and remaining uncertainty.
6. Preserve source attribution for every metric and table.

The Skill uses only an injected earnings Plugin port. It has no Claude,
MCP, slash-command, DSH, or ResearchManager dependency.
