# Valuation Analysis Prompt

Build a transparent valuation package from injected peer data and forecast
inputs. Explain peer selection, compare operating benchmarks and valuation
multiples using min, quartile, median, and max statistics, calculate a DCF
with WACC and terminal growth, and show sensitivity. Bridge enterprise value
to equity value using net debt and shares outstanding.

State the assumptions, terminal-value concentration, peer limitations, and
risks. Treat the output as an analytical valuation artifact, not a trading
instruction.
