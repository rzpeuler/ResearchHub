# Research Output

This directory is the public boundary for user-facing research outputs and
machine-readable Research Objects.

- `reports/` contains rendered research documents.
- `objects/` contains structured Research Object representations.
- `provenance/` contains source and derivation relationships.

The directories are intentionally lightweight in this migration. Existing
`packages/artifacts/` models remain available for compatibility while new
output-oriented code is introduced incrementally.
