# 前端中英语言切换设计

日期：2026-10-03

## 目标与范围

在现有 React 客户端的全局导航中提供中文与 English 切换。默认使用中文；用户选择在本机浏览器中保存，刷新及路由切换后保留。切换仅影响前端编写的导航、按钮、标题、说明、状态、空状态和辅助标签。Theme、公司名称、研报、Knowledge 事实、用户输入、Agent 回复及服务端原样返回的错误内容不做机器翻译。Schema、Workflow、Knowledge 和 Runtime API 不因语言选择改变。

## 方案

由客户端顶层 LanguageProvider 保存 `zh-CN` / `en` 状态，提供显式的 `t(中文, English)` 选择函数。全局导航暴露切换按钮，并同步设置 HTML `lang` 属性。路由页面直接为其拥有的静态文案提供两种语言；专业术语如 Theme、Knowledge、Claim、Workflow、Kill Criterion 可保持英文。选择写入 `localStorage`，读取失败时安全退回中文。语言切换不重建会话、不清空表单、不触发后端写入。

不采用 DOM 扫描或对服务端数据进行通用翻译：前者容易误改动态研究内容，后者会改变证据语义。此次覆盖现有主要页面和常见操作文案；未来新增文案应在组件中显式提供两种语言。

## 验收

- 导航中的语言控制可即时切换主要页面文案，当前路由和输入状态保持不变。
- 刷新后恢复所选语言；无本地保存值或存储不可用时为中文。
- 中文和英文的导航、研究入口、图谱和常见空状态可读；原始知识与研究内容不被翻译。
- TypeScript、相关客户端测试和构建通过；在实际浏览器中核对两种语言。
